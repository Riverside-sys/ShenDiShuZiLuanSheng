# 深地特殊空间数字孪生可视化平台

## 项目介绍

### 项目说明

win11，采用B/S架构，基于 Vue 3 和 Cesium 的深地特殊空间数字孪生可视化平台，主要场景为废弃矿山/矿井、含水层、盐穴，并支持基于视觉、点云建模、地质反演等三维模型的可视化

#### 技术栈

- Vue 3
- TypeScript
- Vite
- Cesium
- Pinia
- Element Plus
- Sass

#### 特点

- 基于视觉与BIM的矿山场景模型的加载、显示、切换
- 后续逐步添加、完善对含水层、盐穴等场景反演模型的可视化

## 项目启动

### 配置说明

#### 确保已配置nvm

运行

```powershell
nvm use 22
pnpm install
pnpm dev
```



或使用预配置的启动脚本

```powershell
./start.bat
```
