# 含水层测井曲线数据

本目录将本地 XLSX 测井资料转换为可直接绘图的 TypeScript 数据。原始工作簿位于
`src/Views/hanshuiceng/data/26-7吉大含水层资料/测井资料数字化/`，受
`.gitignore` 管理，不应提交。

## 使用与生成

- `index.ts`：公开类型、8 口井清单、数据集摘要、每井数据和按井 ID 查询函数。
- `logs.generated.ts`：脚本生成的确定性数据，不应手工修改。
- `index.test.ts`：井 ID、数值有效性、通道语义、抽样约束和代表井精确值测试。
- 生成命令：`python3 scripts/aquifer/generate_logs.py`
- 生成依赖：Python 3 与本机 `openpyxl`，不需要新增 npm 依赖。

生成脚本读取 `Sheet1` 的真实深度和测井列。存在 `Sheet2` 的工作簿中，
`Sheet2` 比 `Sheet1` 多一列“埋深”；脚本会逐行验证两个 sheet 的深度和测井列
完全相同，防止静默读取到不一致的数据。

## 数据语义与抽样

- `sourceLabel` 完整保留原表列名；原表未给出通道单位，因此 `unit` 为 `null`。
- `N参1` 的“自然加码”使用 `naturalEncoded`，明确不推断为自然伽马；
  其真实自然电位、补偿密度和补偿声波分别单独记录，且不生成电阻率通道。
- `samples` 是每井最多 1200 点的可视化子集，不是完整原始序列。
  `originalSampleCount` 和每通道有效/缺失数始终按完整源数据统计。
- 抽样强制保留全井首尾、每通道有效区间首尾及全局极值，再按深度桶保留趋势点和
  相对相邻实测趋势偏差最大的局部点。相同输入始终产生相同结果。
- 所有输出值均来自某个原始单元格；空单元格保持缺失，不插值、不补零。
