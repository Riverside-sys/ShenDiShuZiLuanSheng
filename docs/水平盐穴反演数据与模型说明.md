# 水平盐穴模拟反演数据与展示模型

## 交付与平台入口

平台盐穴主场景顶部新增“水平盐穴三维分析”，路由 `/#/saltCave/subscenes/inversion`。
支持旋转、缩放、三档边界阈值、C4～C9 表面属性着色、点击查询原坐标及插值属性、线框和下载。

### 图表、内部漫游与剖切

- 左侧：完整候选腔体的体积、表面积、三方向尺寸，沿 C3 的候选截面积，以及三种阈值的体积比较。
- 右侧：选定 C4～C9 字段的腔内原始采样点直方图、逐 C3 层的算术平均曲线和点选属性。没有模拟时间序列，所以没有虚构趋势、运行压力或稳定性指标。
- “进入盐穴”：约 2.2 秒穿壁入场，然后沿 C1=30～145、C2=40.25、C3=-531.818 的路线漫游约 16 秒。已验证路线及前方观察目标至 C1=160 在三个阈值下均落在 C9 低值区。入场是演示穿壁，不宣称穿过真实井口；辅助照明不代表现场照明条件。
- 漫游可暂停，暂停或自动结束后可拖动环视；“返回外部”或 Esc 动画退出，恢复原先剖切开关。
- “启用剖切”：C1/C2/C3 三方向可选，滑块 0～100% 控制沿所选轴包围盒的切除距离比例，**不是已切除体积百分比**。支持切换从高值侧或低值侧切除。0% 为完整外壳，100% 隐藏全部外壳。
- 所有剖切只裁剪腔体外壳，不生成填充面或属性封盖，直接显示空腔内壁。已移除“腔内场切片”开关，三个方向及反向剖切均保持空心。
- 点击腔壁查询表面顶点重心插值。已被剖去的面不参与有效查询。
- 沿高程截面积按低值采样点及横向网格间距估算，和三角网格的精确平面求交面积有区别。侧栏几何统计仍表示完整候选模型，不随滑块变成剩余体积。

体网格运行时文件 `volume-grid.json` 按 C-order 保存全部六列属性，索引为 `((ix * ny) + iy) * nz + iz`。数据插值与图表逻辑位于 `inversionVolume.ts`，可执行 `node scripts/verify_salt_cave_volume.mjs` 验证非等距插值、网格顺序、边界处理、直方图计数及漫游路径。

交付目录：`public/models/salt-cave-horizontal/`。

- `cave-c9-0.5.glb`：默认候选模型，可用 Three.js GLTFLoader 加载，约 90 KB。
- `cave-c9-0.1.glb`、`cave-c9-0.9.glb`：边界阈值敏感性版本。
- 同名 `.json`：平台使用的网格和逐顶点属性，positions、indices、sourceCoordinates、attributes；attributes 的六列依次对应 C4～C9。
- `metadata.json`：源文件 SHA-256、字段范围、网格坐标、坐标变换、模型统计和假设。
- `source-grid.csv`：全部 22,491 个原始采样点及全部九列，包含腔体内部属性。

GLB 包含几何与基础颜色。完整属性在 JSON/CSV 中，不能只拷贝 GLB 就获得全部属性。JSON 顶点序号与自身 indices 对应，不假定第三方加载器重排后的 GLB 顶点仍与其一一对应。

## 能确定的事实

原始文件 `src/Views/saltCave/data/盐穴/7.水平腔体.dat` 无表头，22,491 行，每行 9 个有限数值，无重复坐标或缺失网格点。
前三列恰好组成 51 × 21 × 21 笛卡尔积网格。

| C3 | -574.242～-453.030 | 候选 Z 坐标，21 个位置 |

## 重建假设与方法

按“C1～C3 是空间坐标，C9 的低值区域是腔体”这一**未获得提供方确认的假设**，提取 C9=0.5 等值面。
这是模拟反演候选几何，不能称为实测模型。没有字段表，不能给 C4～C8 加上速度、位移、浓度、应力、压力等确定名称。

采用 scikit-image 的 Lewiner Marching Cubes，从原始网格提取三角面，并按各轴实际坐标转换。算法及参数依据：[官方文档](https://scikit-image.org/docs/stable/api/skimage.measure.html#skimage.measure.marching_cubes)。
不做平滑、不添加井筒、不外推、不人为封口。图中两处细长竖向结构本来就在数据中，可能与模拟井筒有关，但不能确认；网格横向分辨率约 3.83，不能据此认为细杆直径有高精度。
表面 C4～C9 采用原始网格三线性插值；页面点选再在三角面顶点间做重心插值，属于显示插值，不是新增模拟结果。

| C9 阈值 | 顶点 | 三角面 | 体积（坐标单位³） | 表面积（坐标单位²） |
| --- | ---: | ---: | ---: | ---: |
| 0.1 | 2,132 | 4,260 | 272,148.21 | 29,011.22 |
| 0.5 | 2,216 | 4,428 | 344,887.36 | 32,517.86 |
| 0.9 | 2,494 | 4,984 | 430,646.72 | 37,768.10 |

三者均为单一连通、法向一致的封闭三角网格。0.9 阈值在竖向结构顶端触及数据域顶部（C3=-453.030），无法确认此处真实终止还是导出范围限制；不能用封闭性证明完整覆盖真实结构。
默认模型三方向包围盒尺寸为 166.727 × 59.049 × 97.643 坐标单位（包含细长竖向部分），C3 范围 -553.367～-455.724。
相对默认体积，0.1 和 0.9 阈值约变化 -21.1% 和 +24.9%。这是阈值敏感性比较，并非统计置信区间。

## 坐标与平台接入

源坐标中心 O=(97.749835, 40.249985, -513.636)。展示坐标变换：

```text
viewerX = sourceC1 - O.x
viewerY = sourceC3 - O.z
viewerZ = -(sourceC2 - O.y)
```

采用右手系旋转，将原 C3 作为竖直方向，不缩放。逆变换为 C1=viewerX+O.x、C2=-viewerZ+O.y、C3=viewerY+O.z。
虽然 glTF 通常使用米制约定，本文件未声明坐标单位，交付模型仅保持原值数值尺度，不声称 1 单位=1 米。若后续确认单位，可在加载时统一比例变换。
没有地理坐标系、井口经纬度、高程基准及方位信息，因此未把它强行贴到现有盐穴群地理位置，也未将原页面的示例压力、容量、岩性数据套用到它上面。

## 复现与验证

```powershell
python -m pip install numpy scipy scikit-image trimesh
python scripts/build_salt_cave_model.py
npm run build
```

脚本检查有限数值、网格完整性、唯一性、低值区未穿过计算域边界、网格封闭性、法向一致性和正体积，另记录表面是否恰好触及边界。生成的 CSV 保留原始数值；源文件保持不变。

要转成工程可解释成果，仍需提供方确认：九列定义与单位、坐标基准与方向、C9 的定义和推荐边界阈值、模拟时间/工况，以及细长结构和导出域顶部的含义。在此之前，本交付可用于明确标注来源的平台演示。

## 展示名词约定

界面使用“水平盐穴三维分析”，数据来源仍是第三方溶腔模拟反演，不因界面名称变化而成为实测成果。C4～C6 称为 X/Y/Z 向场分量，C7 称为矢量模长，C8 称为标量场强度，C9 称为边界系数。这些是数学或展示名称，不给未知字段指定速度、压力、浓度等物理量和单位。“竖向井筒”是依据细长竖向形态采用的展示称谓，实际用途尚无提供方确认。

核心交付仅保留平台组件、三档 GLB 与网格属性 JSON、体网格 JSON、元数据、供下载的完整 CSV、生成脚本及数值验证脚本。调试截图、浏览器日志、打包副本和 PLY 重复格式不保留。原 DAT 由数据提供方交付，位于本地忽略的数据目录；复现时需提供该文件。
