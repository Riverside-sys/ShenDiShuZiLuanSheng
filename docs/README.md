# 开发说明

## 配置与说明

### 项目配置

主要配置文件：

-   tsconfig.app.json：前端应用 TypeScript 配置

-   tsconfig.json：主配置，管理多配置文件和路径别名

-   tsconfig.node.json：Node 相关 TypeScript 配置（如 Vite 配置文件）

-   vite.config.ts：Vite 前端构建工具的主配置文件

本项目可混用 .ts、.js、.vue 文件（tsconfig.app.json 和 tsconfig.node.json 中设置 `"allowJs": true` ）

### 其余说明

-   .vscode：extensions.json 推荐使用的 visual studio code 插件
-   deprecated：存放此前未被实际使用的文件

-   docs：开发与使用说明

-   public：存放三维模型数据，注意与 _src/assets/_ 的区别，assets 更多的是存放与项目紧密相关的资源、配置文件，会在项目构建时一起打包，大多不能随意替换，并且体积不会太大，如 css、图标、字体文件等；public 倾向于存放模型文件，文件体积较大，并在构建时被排除

## src

### assets

| 目录      | 说明                                                                                      |
| --------- | ----------------------------------------------------------------------------------------- |
| aqgk/     | 存放安全管控相关的图片资源（如报警、背景、按钮等 PNG 图），用于安全相关的 UI 展示。       |
| fonts/    | 项目字体文件（如 OTF、TTF），通过 @font-face 引入，供全局或局部字体样式使用。             |
| iconfont/ | 存放 iconfont 字体图标相关文件（如 .css, .json, .ttf, .woff, .woff2），用于矢量图标展示。 |
| icons/    | 存放 SVG、PNG 图标，主要用于界面上的小图标、按钮等。                                      |
| images/   | 存放项目中用到的常规图片资源（如背景、头像、按钮、装饰等 PNG/JPG），用于页面视觉展示。    |
| svgs/     | 存放 SVG 矢量图，供页面各类图标、装饰、背景等使用                                         |

#### 图标文件

推荐使用 [iconfont-阿里巴巴矢量图标库](https://www.iconfont.cn/)

#### 字体文件

借鉴[飞渡科技](https://www.freedoonline.com/) -> [太极开发者平台](https://www.gbim.vip/#/home/main)

| header/          | 头部导航栏相关组件。                                             |
| headerlink/      | 头部链接相关组件。                                               |
| Icon/            | 图标相关的封装组件。                                             |
| features/        | 功能按钮、功能区相关组件。                                       |
| V3Echarts/       | Echarts 图表相关的封装组件。                                     |
| First_title/     | 一级标题样式组件。                                               |
| Second_title/    | 二级标题样式组件。                                               |
| scenes_mines/    | 矿井场景的子场景组件                                             |
| scenes_saltcave/ | 盐穴场景的子场景组件。                                           |
| scenes_aquifer/  | 含水层场景的子场景组件。                                         |
| ui/              | 通用 UI 组件（如卡片、菜单、进度条等）。                         |

#### header，headerlink

三大场景暂时划分为（后续按需修改）：

-   废弃矿山：总览、工艺流程、储能管控、视频监测、环境信息、应急管理

-   含水层：总览、工艺流程、封存管控、卤水监测、环境信息、应急管理

-   盐穴：总览、工艺流程、储氢管控、腔体监测、环境信息、应急管理

前端路由管理模块

### stores

全局状态管理模块

| 目录       | 说明                                              |
| :--------- | :------------------------------------------------ |
| index.js   | Pinia 的入口文件，通常用于创建和导出 store 实例。 |
| animate.ts | 管理动画相关的全局状态（如页面切换动画开关等）。  |
| dialog.ts  | 管理全局对话框的显示/隐藏、内容等状态。           |
| aircity.ts | 管理 AirCity 相关的业务状态。                     |
| tools.ts   | 管理工具栏、功能区等相关的全局状态。              |
| modules/   | 拆分的子模块 store（如用户、点位等），便于扩展。  |

### styles

全局样式配置

| 目录          | 说明                                                                                 |
| :------------ | :----------------------------------------------------------------------------------- |
| global.css    | 全局通用样式，包含页面基础布局、字体、颜色、滚动条、按钮、表格等常用元素的样式定义。 |
| base.css      | 基础样式，主要用于字体、全局背景、常用组件的样式和字体图标（如 iconfont）的引入。    |
| normalize.css | normalize.css，用于统一不同浏览器的默认样式表现。                                    |
| layout.less   | 页面布局相关的样式，通常用于定义 flex/grid 布局、响应式等。                          |

### utils

工具函数与通用逻辑模块，用于存放项目中可复用的、与具体业务无关的辅助函数或工具类

| 文件名             | 作用说明                                                                              |
| :----------------- | :------------------------------------------------------------------------------------ |
| chartConfig.ts     | 图表相关的配置和工具函数，通常用于 Echarts 等图表组件的配置复用。                     |
| modelInfoLoader.js | 三维模型信息加载与处理工具，负责解析模型文件、提取元数据等，常用于三维场景/模型展示。 |
| common.ts          | 通用工具函数，如全局弹窗管理、z-index 计算等，供各处调用。                            |

### Views

用于存放“页面级”组件，即“视图组件”或“路由组件”

| 目录       | 说明                                                                                         |
| :--------- | :------------------------------------------------------------------------------------------- |
| home/      | 核心业务页面，包含首页、各类业务模块（如总览、工艺、储能、视频等），是用户访问的主页面集合。 |
| Platforms/ | 矿井场景的总览平台，如巷道标签显示与点击跳转等功能的组件容器。                               |
| 404/       | 404 页面，用于处理未匹配到的路由                                                             |

与 **components** 对比

| 目录         | 主要内容       | 典型用途                  | 复用性           | 路由关系         |
| :----------- | :------------- | :------------------------ | :--------------- | :--------------- |
| @/Views      | 页面级组件     | 路由页面、业务主页面      | 低（一般不复用） | 直接被路由引用   |
| @/components | 复用型功能组件 | UI 区块、功能模块、弹窗等 | 高（多处复用）   | 不直接被路由引用 |
